Architecture

The site follows a build-time rendering model. All content is processed during next build, producing static HTML files served by GitHub Pages. No server runs at request time.

Content
posts/*.md projects.json resume.json
↓ processed at build time
Build
lib/posts.ts lib/projects.ts lib/github.ts
↓ renders pages
Pages
/ /blog /blog/[slug] /projects /about /resume /contact
↓ static export
Deploy
GitHub Actions → GitHub Pages
Runtime
Formspree (contact form) GitHub API (build-time only)

Build Order

Features are built in dependency order. Four features can be built in parallel after the layout is complete.

system └─ site-layout ├─ blog ┐ ├─ projects-showcase │ parallel ├─ about-resume │ └─ contact-form ┘ └─ home-page (depends on blog + projects)

Key Design Decisions

DecisionWhyWhat else was considered
Static export GitHub Pages serves static files. No server means no costs, no cold starts, maximum reliability. Vercel (supports SSR but adds provider dependency)
Markdown in repo Content is version-controlled with code. Jon edits posts in his IDE, no external CMS. Contentful, Sanity (adds complexity and cost)
CSS Modules Design tokens from DESIGN.md map to CSS custom properties. Scoped styles, no runtime CSS-in-JS overhead. Tailwind (fights the token system), styled-components (runtime cost)
Formspree No server needed for contact form. Free tier covers personal site volume. Custom API route (incompatible with static export)
GitHub API at build Repos update per deploy, not per page load. No rate limiting for visitors. Client-side fetch (rate limiting, loading states)

Glossary

Static export
Generating all pages as plain HTML files at build time, with no server needed to serve them.
App Router
Next.js's file-based routing system where each folder in src/app/ becomes a URL path.
Frontmatter
Metadata at the top of a Markdown file (title, date, tags) used to generate listings and page headers.
CSS custom properties
Variables defined in CSS (e.g., --accent) that enable theme switching and consistent design tokens.
Formspree
A third-party service that receives form submissions via POST request and forwards them as email.
GitHub Pages
Free static site hosting from GitHub, served from a repository's branch or build output.
GitHub Actions
Automated workflows that run on GitHub events (e.g., push to main) to build and deploy the site.
OKLCH
A color space used in the design system that provides perceptually uniform color manipulation.
